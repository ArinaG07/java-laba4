## Описание
Приложение читает список геометрических фигур из текстового файла, вычисляет их площади и периметры, сохраняет список средствами сериализации Java.

## Формат текстового файла
Каждая строка описывает одну фигуру.
- Круг: `Circle <радиус>`
- Прямоугольник: `Rectangle <ширина> <высота>`
  Разделитель - пробел. Пример:
- Circle 5.0\
  Rectangle 4.0 6.0

## Поведение при ошибках
При чтении текстового файла, если строка содержит неизвестный тип фигуры, неверное количество параметров или ошибку преобразования числа, выбрасывается исключение `InvalidFigureFormatException`. Приложение **отклоняет загрузку** и выводит сообщение об ошибке с указанием номера строки. Уже прочитанные фигуры не сохраняются.

## Сборка и запуск
1. Скомпилируйте проект:
   `javac -d out src/app/Main.java src/exceptions/*.java src/geometry2d/*.java src/geometry3d/*.java src/storage/*.java`
2. Запустите:
   `java -cp out app.Main`
3. Следуйте инструкциям в консоли.
